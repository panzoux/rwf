# Phase 7.8 — Leapナビゲーション（高速フィルタ移動）

**作成日**: 2026-06-01  
**状態**: 仕様確定  
**対象**: 高速なキーボードナビゲーション、日本語環境でのIMEレス操作

---

## 1. 目的

RWFに、nnnのNavigate-As-You-Typeに近い操作体系を導入する。単なる検索機能ではなく、「キーボードのみで目的のファイル・ディレクトリへ高速移動するためのナビゲーション機能」と位置付ける。

また、日本語環境ではIME切替が操作の妨げになるため、Migemoを統合し、英数字入力のみで日本語ファイル名へ移動できるようにする。

### **目標**
- IME切替不要
- 入力途中から即座に候補へ移動
- nnnに近い操作感（Auto-Enter対応）
- 大量ファイル（50,000件規模）でも実用速度
- UIをブロックしない非同期処理

---

## 2. 基本動作

- **モード進入**: 専用キー（例: `f` または `/`）でNavigate Modeへ入る。
- **入力バッファ**: モード中は入力を保持し、1文字ごとに現在ディレクトリのエントリに対してマッチングを行う。
- **対象範囲**: 現在表示中のディレクトリのみ（再帰検索は行わない）。
- **評価対象**: ディレクトリ名、ファイル名（フルパスは対象外）。

---

## 3. ナビゲーション・確定ロジック

### **nnn準拠の確定**
- 入力中に候補が複数ある場合、カーソルは最初の候補へ移動する。
- 候補が単一（1件）になった時点で、それが確定候補となる。
- **Auto-Enter**: 確定候補がディレクトリの場合、自動的にそのディレクトリへ移動する。
- **手動確定**: `Enter`, `Tab`, またはnnn互換の確定キーで移動。

### **セグメント方式（AND検索）**
- 入力を区切り文字で分割し、複数のセグメントとして扱う（AND検索）。
- **区切り文字**: `Space`, `/`, `_`, `-`, `.`
- **エスケープ**: `\ ` でリテラルのスペースを検索可能。
- **CamelCase分割**: 有効化されている場合、`TouHouMusic` を `Tou`, `Hou`, `Music` に分割してマッチング。

---

## 4. マッチング・ Migemo アルゴリズム

### **マッチ優先順位**
英数字の操作感を損なわないよう、以下の順位で適用する：
1. **Prefix Match** (前方一致)
2. **Substring Match** (部分一致)
3. **Migemo Match** (日本語ローマ字一致)

### **Migemo仕様**
- **任意機能**: 辞書未ロード時は自動で無効化し、通常検索を継続。
- **開始文字数**: `migemo_min_chars` (デフォルト: 1)。1文字目からMigemoを有効にし、IMEレスを最優先する。
- **Regexキャッシュ**: Migemo展開結果をRegexとして入力文字列ごとにキャッシュし、再生成を禁止する。

---

## 5. パフォーマンス・非同期設計

### **非同期実行・デバウンス**
- **Debounce**: 50〜100ms（設定可能）。高速入力や貼り付け時の負荷を抑制。
- **非同期評価**: 検索評価はUIスレッドをブロックせず、バックグラウンド（WorkerPool等）で実行。
- **最新優先**: 新しい入力が発生した場合、古い検索タスクの結果は破棄する。

### **大量ファイル対応**
- 50,000エントリ規模で実用速度を維持。
- **UI表示**: 検索実行中はスピナー（⠋ ⠙ ⠹）等を表示し、状態を明示。

---

## 6. 設定項目 (config.json)

```json
{
  "JumpNav": {
    "LeapNavigationEnabled": true,
    "MigemoMinChars": 1,
    "SearchDebounceMs": 50,
    "AutoEnterOnSingleMatch": true,
    "EnableCamelCaseSplit": true
  }
}
```

## 7. 測定指標 (KPI)

実装後に以下を測定し、ボトルネックを排除する：
- Migemo展開・Regex生成時間
- 50,000件に対するマッチング応答時間
- UI描画の遅延（入力追従性）
